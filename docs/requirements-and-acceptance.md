# Требования MVP и критерии приёмки

## Роли и состав MVP

| Роль | Цели и права |
|---|---|
| Посетитель/клиент | Просмотр услуг и портфолио, отправка заявки без регистрации. |
| Администратор | Вход по email/паролю; создание и изменение услуг и проектов; просмотр заявок и изменение их статусов. |

P0: главная, услуги с названием/описанием/ценой, раздел стоимости, контакты, форма заявки и валидация. P1: портфолио и административный интерфейс.

## User Stories

### US-01 Просмотр услуг (P0)
Как клиент, хочу просматривать услуги, чтобы выбрать формат мероприятия.

- Показаны только активные услуги в порядке `displayOrder`.
- Карточка содержит название, описание и стоимость «от».
- При ошибке загрузки показано сообщение с возможностью повтора.
- Переход из карточки в заявку сохраняет контекст выбранной услуги.

### US-02 Отправка заявки (P0)
Как клиент, хочу передать параметры события, чтобы организация связалась со мной.

- Обязательны имя (2–100 символов), телефон (6–30), email, формат, дата не раньше сегодняшней и 1–5000 гостей.
- Успешный POST создаёт заявку со статусом `new` и возвращает ID.
- Ошибка не показывается как успешная отправка; данные формы остаются доступными.
- Во время отправки повторное нажатие не создаёт дубль.

### US-03 Просмотр портфолио (P1)
Как клиент, хочу видеть опубликованные проекты, чтобы оценить опыт команды.

- Возвращаются только опубликованные проекты, упорядоченные по `displayOrder`.
- Карточка содержит название, тип, описание и необязательное изображение.

### US-04 Управление контентом (P1)
Как администратор, хочу управлять услугами и проектами.

- Закрытые операции требуют JWT с ролью `Admin`; иначе ответ `401` или `403`.
- Администратор может создавать, изменять и скрывать услуги и публикации.
- Скрытый контент недоступен в публичных списках.
- Поля проверяются по длине и диапазонам до сохранения.

### US-05 Работа с заявками (P1)
Как администратор, хочу просматривать заявки и менять статус.

- Список доступен только администратору, новые заявки идут первыми.
- Статусы: `new`, `inProgress`, `completed`, `rejected`.
- Неизвестный ID возвращает `404`.
- Администратор может удалить заявку после проверки её ID.

## Навигация

Публичный поток: `Главная → Услуги → Портфолио → Заявка`; переход к форме также доступен с главной и карточек. Администратор: `/admin → вход → услуги / портфолио / заявки`.

PostgreSQL и Figma исключены из текущего объёма по указанию заказчика. Существующая БД остаётся MySQL.
