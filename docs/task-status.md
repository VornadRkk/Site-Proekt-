## Что осталось для регистрации на рабочем сайте

Нужно настроить доверенный HTTPS-сертификат и перенаправление HTTP → HTTPS. В репозитории уже есть шаблон `deploy/nginx.https.conf`. Для установки необходимы данные о домене/DNS и административный доступ к серверу. Проверку защищённого транспорта и включение production-регистрации нельзя считать выполненными до проверки сертификата на реальном адресе.

## Что показывает мониторинг

- Доступность API и MySQL.
- Число API-запросов в секунду.
- Задержка API p95.
- Доля HTTP-ошибок 5xx; при отсутствии ошибок отображается 0.
- Число соединений MySQL.
- Запросы MySQL в секунду.
- Время работы MySQL.

В Compose доступны Prometheus http://localhost:9090 и Grafana http://localhost:3000. Дашборд: `/d/dateandtime`, источник данных — Prometheus. Утилита проверяет реальные значения всех восьми панелей, доступность MySQL, состояние Grafana и подключение источника данных. Проверка завершится ошибкой, если метрики отсутствуют или запросы возвращают NaN.

Это проверка контейнерного стенда. Установка Grafana/Prometheus на production-сервер отдельно не выполнялась; обычный workflow деплоя публикует frontend и API.
