# Требования MVP и критерии приёмки

## Роли

| Роль | Возможности |
|---|---|
| Посетитель | Просмотр услуг и портфолио, анонимная заявка. |
| Client | Регистрация, вход, отправка заявки и просмотр только собственных заявок. |
| Admin | Управление услугами и портфолио, просмотр всех заявок и изменение статусов. |

## Публичная часть

- Навигация: главная, услуги, портфолио, контакты и заявка. Отдельного раздела «Стоимость» нет.
- В услугах показываются название, описание и ориентировочная цена «от».
- Основные направления: театрализованные и игровые программы, частные и корпоративные праздники, свадьбы и фестивали.
- В заявке обязательны имя, телефон, email, формат и дата не раньше сегодняшней. Количество гостей не запрашивается и не участвует в расчёте.
- Ошибка отправки не показывается как успех; повторное нажатие блокируется на время запроса.

## Авторизация и личный кабинет

- Регистрация принимает уникальный email без учёта регистра, имя и пароль от 12 символов.
- Пароль хранится только как PBKDF2-SHA256-хэш; публичная регистрация всегда назначает `Client`.
- Ошибка входа не сообщает, существует ли email. Регистрация и вход ограничены по IP.
- Новая авторизованная заявка получает `UserId` и email из JWT; `/api/applications/mine` фильтрует записи по внутреннему ID аккаунта.
- Client при переходе на `/admin` возвращается в личный кабинет; Admin API независимо проверяет роль и отвечает `403` клиенту.

## Качество, безопасность и эксплуатация

- Unit/API-тесты проверяют регистрацию, роль, хэш, дубли email, вход и изоляцию заявок.
- Playwright покрывает регистрацию → заявку → кабинет → отказ в административном доступе.
- k6 проверяет каталог и создание заявки с порогами ошибок и p95 latency.
- Prometheus собирает API и MySQL-метрики; Grafana содержит обзор доступности, запросов, ошибок и времени ответа.
- PR запускает сборку, тесты, CodeQL, dependency audit, Gitleaks, Trivy и пассивный OWASP ZAP.
- Production по-прежнему работает по HTTP на IP, поэтому `Security__EnableClientAuth=false` и клиентские формы входа скрыты. Включение требует домена, DNS и HTTPS.

PostgreSQL и Figma исключены из объёма. Физическая база проекта — MySQL.
