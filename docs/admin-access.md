# Вход администратора через SSH

На сервере настроен отдельный nginx-вход только на `127.0.0.1:8081`. Внешнее соединение шифруется SSH-туннелем; порт 8081 не опубликован в интернет. Публичный вход сайта не включался.

## Что нажимать в Windows

1. Дважды нажмите `Open-Admin.cmd` в корне проекта.
2. В открывшемся окне PuTTY введите SSH-пароль сервера. Ввод не отображается — это нормально.
3. После успешного подключения автоматически откроется `http://localhost:8081/admin`.
4. Логин и пароль сайта возьмите из локального `output/admin-access.txt`: значения `Admin__Email` и `Admin__Password`. Кавычки вокруг значения, если они есть, вводить не нужно. Эти данные отличаются от SSH-пароля root.
5. Отметьте согласие с политикой и нажмите «Войти».
6. Не закрывайте окно PuTTY, пока работаете в панели. После закрытия соединения доступ прекращается.

Нужен установленный PuTTY (`C:\Program Files\PuTTY\plink.exe`). Скрипт содержит только адрес сервера и проверенный публичный fingerprint; пароль в коде не хранится. При занятом локальном порте 8081 сначала закройте старый туннель.

## Что доступно в панели

- **Услуги**: заполнить название, описание, цену, отметить согласие и нажать «Добавить». «Изменить» открывает последовательные диалоги. «Скрыть» убирает услугу из публичного списка.
- **Портфолио**: добавить название, тип и описание проекта, отметить согласие; редактировать или снять проект с публикации кнопкой «Скрыть».
- **Заявки**: посмотреть контакты и событие, выбрать статус «Новая», «В работе», «Завершена», «Отклонена». Статус сохраняется при выборе. Удаление заявки после подтверждения безвозвратное.
- **Выйти**: завершить сессию в текущей вкладке.

## Сервер: что обнаружено

Ubuntu 26.04 LTS, MySQL 8.4; nginx и API работают. В логах 13–14 ноября есть автоматические обновления ядра, libc и системных пакетов. Сервер сообщает о необходимости перезагрузки после обновлений; в рамках этой работы перезагрузка и обновление пакетов не выполнялись. Grafana, Prometheus и Docker на VPS не установлены. Мониторинг в репозитории относится к Compose/CI-стенду.

Настройка nginx: `deploy/nginx.admin-tunnel.conf`, установлена как `/etc/nginx/sites-available/dateandtime-admin-tunnel` и подключена в `sites-enabled`. Корень сайта указывает на `current/frontend`, поэтому переключение релизов при деплое сохраняет работу приватного входа.

`output/` и `tmp/` исключены из Git. PDF-отчёты и файл учётных данных остаются только локально. Учётные записи и пароли на сервере не менялись; данные клиентов не редактировались.
